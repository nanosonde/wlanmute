# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.3.0] - 2026-11-13

### Added

### Documentation

- Document network names and Windows startup

## [0.2.0] - 2026-11-13

### Added

- **ui:** Show recent activity in a live table

### Documentation

## [0.1.0] - 2026-11-13

### Added

- Add wlanmute tray utility that prefers Ethernet over same-subnet Wi-Fi
